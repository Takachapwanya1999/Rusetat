# Header design alternatives

`header-options.html` contains five alternative Rusetat navigation/header compositions on one review page. The production header is unchanged. The existing solid-purple homepage button edits remain in the working tree separately.

The preview uses the existing logo and home photograph from `../images/`, with no external libraries. It has working service dropdowns, mobile menus, Escape/outside-click dismissal, option jump links and a full/phone-width toggle. Copy this HTML to `dist/header-options.html` to view it through the local site server. It is intentionally not copied by the production build.

Direction: preserve Rusetat's supplied identity, navy/purple palette, Georgia/Arial pairing and travel photograph; reduce the competing utility strip and navigation surfaces. Compare five structures, rather than five accent-colour changes. Options: single navy row, white navigation, inset floating navigation, agency masthead and centred identity.

Review checklist: all five previews load; logo remains legible on each background; dropdown and mobile links work; selected width is communicated; Escape closes and returns focus; desktop/984px/390px/320px containment; original website header unchanged. Exploratory cases: a rightmost dropdown and the narrow floating header with its menu expanded.

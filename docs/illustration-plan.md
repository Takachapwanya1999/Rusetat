# Rusetat page illustration plan

Version 1 · 1 November 2026 · Planning document for review

**Layout update:** the owner's later direction replaces a universal subpage
composition with [branch layout families](branch-layouts.md). Keep the page-level
art briefs below, but treat the old copy-left/stamp-right placement as historical.
The current build uses different intro, body and reading structures for each main
service path while keeping the same stamp family and grey subpage palette.

## Direction to approve

Every page except Home gets a quiet, light-grey hero. The hero contains the page copy on the left and one unique Rusetat rubber-stamp illustration on the right. The stamp is the page’s visual signature: its scene, caption, frame and scale change with the page, while the ink behaviour, lettering, line economy and palette stay consistent.

Home remains the exception. It keeps the existing full photographic hero because it is the entry point into the wider journey. The subpage system should feel calmer and more editorial so the stamp and copy can carry the meaning.

### Subpage hero contract

| Property | Proposed rule |
|---|---|
| Background | Neutral light grey `#EEF0F2` or `#F0F1F2`; confirm one final token after visual review |
| Copy | Dark Rusetat blue `#092D53`; Georgia heading and Arial body, using current site type |
| Stamp ink | Default `#092D53`; one ink colour per impression |
| Layout | Copy block left, stamp right; generous whitespace; no photograph behind the hero |
| Desktop stamp | 280–420px wide, optically aligned to the copy block |
| Mobile stamp | 200–280px wide below the copy, never behind text |
| Shape | Oval, circle, rounded rectangle, squared rectangle or restrained clipped rectangle |
| Texture | Broken edges, local dry patches and small pinholes; no heavy grunge or noise overlay across the page |
| Caption | Short uppercase phrase specific to the page; never an approval or government-status claim |
| Supporting image | May appear lower on the page. Do not place a photograph inside the stamp |
| Home | Existing photographic hero remains; no grey subpage treatment |

The current generated inline stamp is useful for proving the component and uniqueness logic. The subpage hero now reserves the former image slot for the stamp, with a light-grey background and the page copy alongside it; Home remains the photographic exception. The following concepts are the art briefs to review one by one.

## How to review one stamp

For each route, review the concept in this order: does the subject match the page promise, is the caption honest, does the shape help the composition, is the scene simple enough to read at phone size, and does it still look like the same physical ink impression as the other pages? Revise the brief before generating the asset if any answer is no.

## Production sequence

Work through the plan in reviewable batches, with one final artwork approved before starting the next:

1. Approve the grey hero treatment and the stamp grammar using Home, Travel, Visas, Contact and one country page as the first five-page set.
2. Approve the five frame families and the small-use line/texture treatment.
3. Produce the parent routes: Travel, Visas, South Africa visas, International visas, Au Pair, Recruitment, About, Guides and policy pages.
4. Produce the child/service routes, then destination and country routes.
5. Review all desktop and phone heroes together for repetition, readability, contrast and honest meaning.
6. Replace the current generated inline placeholders with approved page assets or a reviewed deterministic vector family, keeping the route-to-art mapping in provenance.

## Acceptance gate for each illustration

- It names the page’s actual subject in one glance.
- It uses the grey hero layout with copy and stamp clearly separated.
- Its frame and scene are unique within the page family without looking unrelated to Rusetat.
- It uses one approved ink colour and the shared imperfect impression texture.
- It contains no government crest, approval claim, fake date, application number or official document detail.
- Its embedded caption is correctly spelled and remains legible at phone size.
- It has an alt-text decision and a matching HTML heading/copy label.
- It passes the final desktop, 390px phone and 200% zoom review.

# Useful chat entry points

The shared contact panel already appears on every generated page. Additional
placements should open that same panel on deliberate selection, rather than
loading several chat embeds or interrupting visitors automatically.

| Location | Suggested action | Entry |
|---|---|---|
| Destination collection, after results | Ask Ruse about your trip | Main chat |
| Individual destination, beside enquiry action | Ask about this destination | Main chat |
| Visa hub and visa detail pages | Start a visa assessment | Assessment |
| FAQs, after an answer or at the end | Still have a question? Ask Ruse | Main chat |
| Contact page, alongside enquiry and WhatsApp | Chat with Ruse / Visa assessment | Both |
| Recruitment and Au Pair pages | Ask about the next steps | Main chat |

Prioritise destination enquiries, visa assessment and FAQs/contact. Retain the
human-contact options. Add contextual destination or visa input only when the
hosted chat supports it; a button must not claim it sent context that was never
received. These are placement recommendations, not newly installed embeds.
The existing hosted-theme deployment and exact new-tab conversation handoff
remain outstanding, as recorded in `chat-integration-status.md`.

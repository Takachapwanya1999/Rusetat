Check spelling, scene meaning, texture density, shape balance, grey-hero contrast and phone-size legibility before approving the family.

The PNGs were generated with the built-in imagegen tool using `assets/illustrations/rusetat-travel-migration-stamp.png` as a style reference. They are brand illustrations, not official immigration stamps, government seals or evidence of approval.
